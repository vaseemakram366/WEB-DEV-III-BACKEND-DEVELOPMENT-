# Lecture 10 Student API

This project contains a simple REST API built with Node.js and Express. It demonstrates the four basic CRUD operations using an in-memory list of students:

- **Create** a student
- **Read** all students or one student by roll number
- **Update** a student's details
- **Delete** a student

Because the data is stored in a JavaScript array, changes are lost whenever the server restarts. No database is used.

## Requirements

- Node.js and npm

## Installation

From this directory, install the dependencies:

```bash
npm install
```

## Running the server

Start the server with Node.js:

```bash
node server.js
```

For automatic restarts during development, use the configured npm script:

```bash
npm run cr7
```

The API is available at:

```text
http://localhost:3000
```

## Middleware

The server uses `express.json()` to parse JSON request bodies. Requests that send student data should use:

```http
Content-Type: application/json
```

## API endpoints

### Get all students

```http
GET /students
```

Returns the complete student array.

Example response:

```json
[
  { "rollNo": 1, "name": "Krishn", "section": "Core-B" },
  { "rollNo": 2, "name": "ayan", "section": "Core-B" }
]
```

### Get one student

```http
GET /students/:rollNo
```

Example:

```http
GET /students/1
```

Successful response:

```json
{
  "success": true,
  "student": { "rollNo": 1, "name": "Krishn", "section": "Core-B" }
}
```

If the roll number does not exist, the endpoint returns HTTP `404`:

```json
{
  "success": false,
  "message": "student not found"
}
```

### Create a student

```http
POST /students
```

Send a JSON body containing the student's details:

```json
{
  "name": "Riya",
  "section": "Core-A"
}
```

The server assigns a roll number using the current array length plus one and returns:

```json
{
  "success": true,
  "message": "student created successfully",
  "data": {
    "rollNo": 6,
    "name": "Riya",
    "section": "Core-A"
  }
}
```

### Update a student

```http
PUT /students/:rollNo
```

Example:

```http
PUT /students/1
```

Request body:

```json
{
  "name": "Krish",
  "section": "Core-A"
}
```

Both `name` and `section` are optional. Fields omitted from the request keep their existing values.

Successful response:

```json
{
  "success": true,
  "student": { "rollNo": 1, "name": "Krish", "section": "Core-A" }
}
```

An unknown roll number returns HTTP `404` with the same `student not found` response described above.

### Delete a student

```http
DELETE /students/:rollNo
```

Example:

```http
DELETE /students/1
```

Successful response:

```json
{
  "success": true,
  "message": "student deleted successfully"
}
```

An unknown roll number returns HTTP `404` with the same `student not found` response described above.

## Testing with curl

```bash
curl http://localhost:3000/students
curl http://localhost:3000/students/1
curl -X POST http://localhost:3000/students -H "Content-Type: application/json" -d "{\"name\":\"Riya\",\"section\":\"Core-A\"}"

curl -X DELETE http://localhost:3000/students/1
```

## Current limitations

- Data is held only in memory and is not persisted.
- There is no validation for required fields or malformed student data.
- Roll numbers are generated from the array length, so deleting records can lead to duplicate roll numbers after later inserts.
- The 404 branches send an error response but do not currently stop execution with `return`; this can cause an additional response attempt for missing records. This is behavior in the current `server.js` and should be corrected before using the API beyond this exercise.
